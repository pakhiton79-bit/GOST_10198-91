# Расчёт ящика — ГОСТ 10198-91, тип 1, комплектация 3

Производственный калькулятор — однофайловый HTML (расчёт + печатная спецификация
+ чертежи расположения деталей на фото). Итоговый файл для использования —
`dist/calc.html`, но редактировать его напрямую не нужно: он собирается из
`src/`.

## Структура

- `src/calc.src.html` — HTML-каркас (разметка форм, таблиц, дропдаунов), ~190
  строк. Содержит плейсхолдеры `/*__STYLE_CSS__*/`, `/*__LOGIC_JS__*/`,
  `/*__DIAGRAMS_JS__*/`, `/*__APP_JS__*/` — вместо них при сборке подставляется
  содержимое файлов ниже.
- `src/style.css` — вся CSS-вёрстка (тема, формы, таблицы, печать).
- `src/logic.js` — чистые расчётные формулы ГОСТ (толщины, сечения полозьев,
  Таблица 19 и т.п.) — без обращений к DOM. Правки формул/таблиц ГОСТ — сюда.
- `src/diagrams.js` — константы картинок (`*_IMG_B64`, плейсхолдеры вида
  `__IMG:dno.png__`) и все функции `diagram*()`, рисующие чертёж поверх фото
  (SVG-стрелки + подписи). Добавление/правка чертежа — сюда.
- `src/app.js` — UI (фильтр толщин, тип крепления), сама `calculate()` и вся
  логика печати (масштабирование на одну страницу А4, резерв места под вылет
  подписей).
- `src/images/*` — сами картинки чертежей (PNG/JPG), отдельными файлами.
- `build.py` — собирает всё перечисленное выше + `src/images/*` в готовый
  `dist/calc.html` (подставляет содержимое файлов вместо плейсхолдеров,
  заменяет `__IMG:...__` на base64).

## Сборка

```
python3 build.py
```

Результат — `dist/calc.html`, полностью самодостаточный файл (можно открывать
локально в браузере без интернета, кроме шрифта Google Fonts).

## Зачем так

Единый HTML-файл с картинками в base64 — это 1+ МБ текста в одной строке на
картинку, поэтому картинки вынесены в `src/images/*` отдельными файлами.
Дополнительно сам код разбит на `style.css`/`logic.js`/`diagrams.js`/`app.js`
вместо одного файла на 2500+ строк — так типичная правка (один чертёж, одна
формула ГОСТ) требует читать только небольшой профильный файл, а не весь
калькулятор целиком. Финальная склейка в единый файл — чисто механическая,
без модели.

## Добавление нового чертежа

1. Добавить файл картинки в `src/images/`.
2. В `src/diagrams.js` добавить константу вида
   `const XXX_IMG_B64 = "data:image/png;base64,__IMG:xxx.png__";`.
3. Там же добавить функцию `diagramXxx()` с массивом `records` (координаты
   стрелок/подписей в пиксельных координатах картинки) — см. соседние функции
   (`diagramDno`, `diagramKryshka` и т.д.) как образец.
4. Пересобрать: `python3 build.py`.
