# WOODCALC --- UI DESIGN SPEC v1.0

**Цель:** разработать минималистичный промышленный интерфейс для
калькулятора производства деревянной тары.

## Общая концепция

Стиль должен напоминать современную ERP/MES систему, а не декоративное
приложение. Интерфейс: белый, строгий, максимально функциональный.
Единственный акцентный цвет --- тёмный орех.

### Ключевые ассоциации

-   производство
-   деревообработка
-   точность
-   инженерный софт
-   минимализм
-   большие таблицы
-   высокая читаемость

# Финальный результат

Нужно реализовать полноценный desktop-first интерфейс с компонентами:

-   Sidebar
-   Topbar
-   KPI Cards
-   Editable Data Table
-   Right Summary Panel
-   Forms
-   Buttons
-   Dialogs
-   Light theme only

Использовать React + Tailwind + shadcn/ui.
